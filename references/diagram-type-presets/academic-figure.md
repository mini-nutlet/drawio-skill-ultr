# Academic Figure Preset

## Layout: LAYERED or FLOW
## Default Theme: editorial (monochrome + red accent ONLY)
## Node Budget: ≤15 nodes, ≤20 edges

## Overrides from Editorial Theme
- Color is NEVER the sole carrier of meaning
- Legend is mandatory when symbols/colors/lines differ
- Font: Times New Roman, 11pt
- Formula delimiters: $$...$$ (standalone), \(...\) (inline)
- Canvas: A4-L (1123×794) or as specified by venue

## Caption Convention
- Below figure: "Figure N: Description..."
- Font: Times New Roman, 9pt

## Quality Gates (additional)
- Node budget check: >15 nodes → suggest split or simplify
- Labels readable at A4 print scale
- Captions/legends/callouts not clipped
- Venue-specific column width compliance (IEEE: 89mm single, 183mm double)
